# Raport / Opis:
Każda strona została wypełniona przykładowymi treściami, zawiera sekcje i podstrony.
Dodano elementy interaktywne oraz animacje.
Media - zdjęcia oraz ikonky jako przykładoła demonstracja.
Style opracowano samodzielnie, a kod został napisany ręcznie.
Każda strona ma podstawowe mobilne adaptacje.
Dodatkowo, część refaktoryzacji kodu została wykonana przy wsparciu AI.
Tworzone commit'y za pomocą GIT (każda strona - osobny git repozytorium).
